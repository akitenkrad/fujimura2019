# Visualization

[English] | [日本語](visualization.ja.md)

With no `--results-dir` the tools ask runvault for the latest finished run of the subcommand they need (`runvault path --experiment fujimura-silence --latest --subcommand run` / `--subcommand sweep`); pass `--results-dir` to target another run — a runvault parent, a single run, or a pre-runvault `results/<timestamp>/` directory.

Figures and `sem_fit.json` go to `results/fujimura-silence/figures/<run_slug>/`, outside the run directory: `manifest.csv` is settled when the run finishes, so a figure drawn afterwards is not part of the record. `--output-dir` overrides that.

## `fit-sem`

Estimates the ABM-induced SEM with [semopy](https://semopy.com/) from the agent panel, pooled across the run's replicate children: builds one cross-sectional row per agent (time-averaged latent states + behaviour frequencies, excluding t=0), fits

```
fear ~ psafety ; acquiescent ~ fear ; voice ~ fear ; silence ~ acquiescent
```

and writes `sem_fit.json` with the standardized β̃, Wald 95% CIs, fit indices (CFI / GFI / RMSEA / χ²), `corr_silence_voice`, and the sign-match count against the paper anchors. Falls back to per-path OLS if semopy is unavailable.

## `visualize`

Reads the replicates' per-step metrics (and `sem_fit.json` if present) and writes:

- `timeseries.png` — silence_rate / voice_volume / climate_of_silence over t, with the paper anchors (silence ≈ .38, voice ≈ .45) dotted.
- `motive_mix.png` — the 4-motive within-silent share trajectory.
- `path_diagram.png` — the SEM path diagram annotated with the estimated β̃ next to the paper values.

## `visualize-sweep`

Reads one row per trial from the sweep children's `terminal` events and writes:

- `sweep_level_forest.png` — final silence_rate / voice_volume per hierarchy level L (mean ± SD), with the paper anchors.
- `sweep_climate_heatmap.png` — mean climate_of_silence over the (η × network_beta) grid — the structural conditions for the global silence spiral.

## `reproduce`

Runs `fit-sem` if needed, then writes `paper_fig1_path_diagram.png` (Fig.1-style) and `reproduction_report.json`, and prints the B1–B5 reconciliation table (sign match + CI overlap + the H5 silence ⊥ voice check).

## `show-experiment-settings`

Prints the run's conditions (`config.json`'s `parameters`) and, for an LLM run, the `llm` block plus the `llm_*` run-scope metrics. `--subcommand` chooses which run to resolve when `--results-dir` is omitted; `--json` gives machine-readable output.
